Submission Format

Submit predictions for both tasks in one file. The recommended format is a JSON file with two top-level objects, task1_static and task2_realtime_prefix5. Each object maps flow_id to the predicted application label. 

{
  "task1_static": {
    "flow_000007": "google",
    "flow_000026": "mozilla"
  },
  "task2_realtime_prefix5": {
    "flow_000007": "google",
    "flow_000026": "x"
  }
}

Alternatively, participants may submit a ZIP file containing exactly two CSV files: 

task1_static.csv
task2_realtime_prefix5.csv

Each CSV file must have the following two columns: 

flow_id,app
flow_000007,google
flow_000026,mozilla

Allowed Labels

Predicted labels must be one of: facebook, google, instagram, mozilla, x, or youtube.

Required Supporting Materials

Participants are expected to retain and submit, when requested by the organizers, the source code used for training and inference and a short technical report describing the selected features, model architecture, training procedure, validation results, treatment of class imbalance, and computational cost.
