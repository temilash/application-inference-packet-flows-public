Terms and Conditions

Participants must use the released data only for this challenge and must follow all restrictions described on the challenge page and in the dataset README.

The participant-facing feature files intentionally exclude IP addresses, DNS query names, TLS SNI, HTTP Host values, URLs, domain strings, and payload contents. Participants must not use private labels or recover prohibited direct identifiers for prediction. If any additional information beyond the released feature files is used, it must be clearly disclosed in the submitted technical report.

For Task 2, participants must use only the task2_realtime_prefix5/ files. Using full-flow features from Task 1 to generate Task 2 predictions is not allowed.

The organizers may inspect submitted code, reports, and prediction files to confirm compliance. Submissions that use private labels, disallowed features, or otherwise violate the challenge rules may be removed from the leaderboard.
